拍张发票，凭证自己长出来

全量凭证、账簿与报表一键导出 Excel / PDF，开放 API 对接业务系统，不做数据绑架。

常见问题

你可能
想了解这些

还有别的问题？登录后可在系统内查看完整帮助文档。

需要安装客户端吗？

不需要。云财是纯在线的财务系统，打开浏览器登录即可使用，换台设备也能接着做账。

一个账号可以管理多家公司吗？

可以。一个账号支持创建多个账套，账套之间数据完全隔离，在顶部随时切换，互不干扰。

历史凭证怎么迁移？

在「凭证导入」中上传符合模板的 Excel（.xls / .xlsx）文件即可批量导入，系统会自动补建缺失科目，借贷平衡的凭证导入后直接入账。

报表数据是实时的吗？

是。科目余额表、资产负债表、利润表、现金流量表都从已过账凭证实时归集计算，期初余额一并参与，任意期间可即时切换。

期末结转和结账怎么处理？

系统提供一键结转损益与批量结账，自动生成本年利润结转凭证并直接过账；资产负债表会把损益并入未分配利润，保证结转前后口径一致。

能直连电子税务局和银行吗？

电子税务局已接通数字账户，发票、申报记录与完税证明可以在系统内直接取回，个税走自然人电子税务局扣缴端；银行流水支持按模板导入并自动归类，直连同步正在陆续开通。
