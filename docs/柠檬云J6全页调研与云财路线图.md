# 柠檬云 J6「云财务（软件版）」全页功能调研与云财对标路线图

> 调研对象：柠檬云财税 j6.ningmengyun.com（云财务·软件版），演示账套「浙江数从科技有限公司」，小企业会计准则、小规模纳税人，启用期间 2026 年 01 月、空账套。
> 调研方式：隔离浏览器登录后逐页访问，全量截图存档 + 页面 DOM 提取，对关键弹窗/下拉做交互取证；全程只读，未改动账套数据。
> 覆盖范围：左侧菜单 11 个分组、70 个页面（含全部二级菜单页）。文中路由为站内路径，省略 `appasid` 等会话参数。
> 证据说明：个别未展开弹窗 / 下拉选项取自页面 DOM 中的界面模板（无法逐张截图），属该应用既有元素。

## 一、系统总览

### 1.1 整体框架

- **产品结构**：面向小微企业的云端财务软件，免费版 + 专业版两档（演示账号为免费版，常驻"升级专业版"引导，但功能页面无硬拦截）。
- **多产品矩阵**：云财务（本系统）、云进销存、AI 开票、一键取票、智能报税、收票宝、老板看账，通过账套与「关联云发票 / 关联进销存」设置打通。
- **顶部栏**：账套切换、当前会计期间选择、新手指引、帮助中心、学习中心、更多、消息中心、账号。
- **左侧菜单**（11 组）：首页 / 凭证 / 资金 / 发票 / 工资 / 资产 / 期末结转 / 账簿 / 报表 / 一键报税 / 设置；底部另有：升级专业版、前往云进销存、AI 开票、前往财务免费版。
- **工作区**：多页签模式（"首页 | 当前页"），支持关闭当前页/其他页/全部、刷新当前页；右侧为悬浮帮助栏（升级专业版、AI 助手、在线客服、免费导账、下载 APP、福利领取）。
- **全局交互约定**：期间选择（绿色标签 + 漏斗筛选）；列表页统一为"工具条（筛选 + 按钮组）+ 表格 + 分页（每页 20/50/200/500/1000）"；空态文案；"导入 / 导出 / 打印"三件套；表格右上角"列设置"齿轮。

## 二、逐页功能详录

### 2.1 首页（1 页）

**首页 · `/Default/Default`**
- 四张快捷卡片：查看凭证、科目余额表、资产负债表、利润表；中部大按钮"新增凭证"。
- "2026年01月财务指标"面板：货币资金 / 应收账款 / 存货 / 固定资产 / 应付账款 + 综合税负率 / 应交税费 / 营业收入 / 利润额 / 净利率，支持月度 / 年度切换；空账套显示"--"。
- 顶部导账服务引导横条；下部为产品宣传横幅。登录后落点即此页；左侧菜单在所有页面恒定呈现。

### 2.2 凭证（4 页）

**新增凭证 · `/Voucher/NewVoucher`**
- 凭证头：凭证字（下拉，默认"记"）、凭证号（自动续号）、日期（默认账套期末日）、附单据__张、附件、备注、放大、全屏。
- 分录网格：序号｜摘要｜会计科目｜借方金额｜贷方金额（金额按"亿千百十万千百十元角分"分栏录入）；默认 4 行；底部"合计：零元整"、"制单人：会计002"。
- 操作：保存并新增 / 保存 / 打印▾ / 更多▾ / 快捷键 / 上一页、下一页（连续录凭证）；页内提示"亲，按回车键，能快速选择单元格哟！"。
- 科目单元格支持"科目名称 / 编码 / 拼音首字母"联想搜索；"更多 / 快捷键"提供录入辅助与操作说明入口。

**查看凭证 · `/Voucher/VoucherList`**
- 工具条：新增凭证、打印▾、电子账簿、导出▾、导入凭证、整理凭证、批量操作▾、更多▾、回收站、刷新。
- 表格（空态列头）：摘要｜科目｜借方金额｜贷方金额；有数据时按凭证分组展示（操作入口未在空态中呈现）。
- 期间筛选 + 排序（凭证号 / 凭证日期，升 / 降序）；"整理凭证"、"回收站"为配套的凭证维护入口。

**会计电子档案 · `/ERecord/ERecord`**
- 左右两栏：左侧档案列表（页签：电子档案列表 | 电子档案归档），右侧"存储空间"卡片（0/10MB + 升级扩容）与目录树（凭证附件 / 回单 / 发票 / 现金流水 / 票据 / 工资 / 资产 / 数据备份）。
- 列：文件名称｜文件类别｜单据类型｜上传日期｜关联单据｜关联单据号｜凭证｜事项｜校验状态｜文件状态｜上传人｜上传方式｜大小｜纸质档案｜路径。
- 操作：收票宝上传、电脑上传▾、审核▾、关联凭证▾、生成凭证▾、标记为纸质档案、更多▾；复选"文件名增加凭证号"。

**收票宝 · `/MiniProgramBinding/MiniProgramBinding`**
- 开通引导页（员工手机采票 → 财务审批归档）；"立即授权"进入绑定向导（打开收票宝 / 分享给员工 / 员工绑定三步）。
- 与电子档案的"收票宝上传"衔接，面向员工协同采票场景。

## 三、跨页机制与设计要点（面向复刻）

1. **出纳 → 凭证闭环**：日记账行内录入 → 勾选流水 → 生成凭证（合并策略：合并成一张 / 按日期 / 按收支类别 / 按收支方向 / 按账户 / 相同借方科目 / 相同贷方科目；并支持智能匹配往来单位、AI 智能生成）；另有"关联凭证"手工挂接。数据从"账户设置 → 日记账 → 核对总账 / 资金报表"形成完整链路。
2. **智能匹配字典体系**：收支类别的"智能匹配关键字"（摘要词典，如 销售 / 回款 / 货款 → 销售收入）+ 科目联想（编码 / 名称 / 拼音首字母）+ 凭证模板摘要预填，三者共同降低录入成本。
3. **辅助核算七类与账页透视**：客户 / 供应商 / 职员 / 部门 / 项目 / 存货 / 现金流七类档案；科目挂载（可设必录）；账页三种透视——科目横向展示、主次类别组合（客户×项目）、多栏账按下级科目展开。**现金流维度挂在现金 / 银行类分录上，是现金流量表自动取数的前提**。
4. **报表机制**：固定行次 + 行级"取数公式"（科目 + 运算符号 + 规则，可编辑）；现金流量表配"报表底稿"做逐凭证归集追溯；资产负债表带"往来科目重分类 / 应交税费重分类"开关；统一支持"显示上年累计"。报表可打印 / 导出 / 分享。
5. **期末闭环**：两段状态机（"已结转损益"与"已结账"分开判定）+ 批量结账 + 反结账 + 期末检查（结账前拦截未过账 / 不平衡 / 缺期初）。
6. **基础数据与账套**：多账套（卡片管理、回收站、复制）；会计准则与编码方案决定科目预置；期初支持试算平衡；凭证字（记 / 收 / 付 / 转 + 打印标题 + 默认字）。
7. **数据进出与留痕**：导入矩阵（科目 / 凭证 / 流水 / 发票 / 旧账）；导出支持"当前 / 全部"两种范围；打印分"列表 / 凭据"两套模板；操作日志（页面级）；备份三产物（可恢复数据包、归档 Excel、归档 PDF）+ 下载中心。
8. **免费版经营设计**：功能页面不设硬拦截，以额度（附件空间、发票份数、多成员、自动备份）与展示（升级引导、专业版试用遮罩）驱动付费——功能与商业化可分离复刻。

## 四、云财现状与差距对照

### 4.1云财现状（代码盘点；含工作区在途改动）

- **技术栈**：.NET 10 + EF Core / PostgreSQL 后端、React + Vite 前端；JWT 单用户体系，无角色 / 权限模型。
- **已具备**：账套（多账套、编码方案在线重建、结账 / 反结账锁期）；科目（树形、编码方案校验、导入导出）；期初（末级录入、试算平衡）；辅助核算（七类档案、科目维度设置、凭证分录取值）；凭证（草稿 → 审核 → 过账状态机、导入、导出端点）；资金（现金 / 银行账户、流水增删改、单条流水生成凭证、导入导出模板、收支类别字典）；账簿 10 页（科目余额表、明细账、总账、序时账、凭证汇总表、多栏账、核算项目余额 / 明细 / 交叉、账龄分析）；报表（资产负债表、利润表）。
- **既有口径**：账簿与报表只统计已过账凭证；查询区间按自然月归一；余额按"借 − 贷"净额、输出层拆分借贷。

### 4.3 小结

硬缺口收敛为三条主线：**(1) 账务闭环**（结转损益 → 结账）；**(2) 出纳闭环**（内部转账、批量合并生成凭证、资金报表、核对总账）；**(3) 报表扩张**（现金流量表为首）。平台化能力（权限 / 日志 / 备份 / 导入）可独立穿插安排；发票 / 工资 / 资产 / 报税属独立业务面，按需立项。

## 五、对标开发路线图

### 5.1 排期原则

- **先补闭环、再扩面积**：结转损益与出纳闭环决定"账能不能走完"，优先级最高；独立模块（发票 / 工资 / 资产）工作量最大、依赖最少，放最后按需立项。
- **口径与地基复用**：新增账页 / 报表一律建立在既有"已过账 + 自然月 + 净额"口径与账簿聚合之上，不另起炉灶；期末结转直接复用账簿聚合的科目期间发生额。
- **一个阶段一个可验收交付**：每阶段结束必须整体回归一次"凭证 → 账簿 → 报表"数字链。

### 5.2 阶段划分

**阶段 1 · 账务闭环：期末结转与结账**（对标：期末结转页；规模 M）
- 结转损益向导：生成结转凭证（损益类 → 本年利润；本年利润 → 未分配利润）；支持"收入和成本分开结转"选项；自定义结转模板（摘要 / 科目 / 取值方向，可复用）。
- 期末检查：结账前拦截未过账凭证、试算不平衡、期初未设置等，并给出定位入口。
- 结账状态机：未结转损益 / 已结转损益未结账 / 已结转损益已结账（与现有账套结账、反结账合并），支持批量结账。
- 验收要点：结转凭证生成后可被账簿 / 报表正确统计；结账 / 反结账无非法状态跳变。

**阶段 2 · 出纳（资金）闭环**（对标：资金组 9 页；规模 M–L）
- 账户设置增强：现金 / 银行存款分页签、账户绑定会计科目（必填校验，未绑定拦截提示）、启用 / 停用。
- 银行日记账独立视图（复用流水组件，按账户类型过滤）；银企互联以"对账单导入"降级实现。
- 内部转账：转出 / 转入账户、金额、生成转账凭证。
- 批量生成凭证：勾选多条流水 → 合并策略（按日期 / 收支类别 / 收支方向 / 账户 / 相同借贷方科目合并）+ 智能匹配往来单位（依赖辅助核算档案）。
- 资金报表：按账户 / 收支类别 / 往来单位 / 项目 / 部门 / 组合六维汇总（收入、支出、余额、笔数）。
- 核对总账：出纳账 vs 总账差异表（"只显示不平"），依赖账户-科目绑定。
- 收支类别增强：智能匹配关键字、关联现金流字段。
- 票据管理：票据台账 + 生成凭证（可独立后置）。

**阶段 3 · 凭证与账簿增强**（对标：凭证组 4 页 + 账簿组 10 页；规模 M）
- 凭证模板：预置高频模板（提现、利息、手续费、报销、采购、销售、计提工资、缴税等）+ 维护页。
- 凭证录入增强：附单据数 / 附件、保存为草稿与模板、整行复制、余额反算、红冲。
- 凭证列表增强：批量操作、整理断号、回收站、打印套打（模板可后置）。
- 凭证字管理页（记 / 收 / 付 / 转 + 默认 + 打印标题）。
- 账簿查询面板统一升级：科目区间表达式（如 `5001,5051,5601-5603`）、显示辅助核算 / 对方科目 / 余额 0 不显示等开关、打印当前 / 全部、导出全部。
- 数量金额式与外币核算：分两小批（先数量后外币），贯通凭证分录、账簿列与报表口径。

**阶段 4 · 报表体系扩张**（对标：报表组 13 页；规模 M–L）
- 现金流量表（公式法取数 + 报表底稿）：依赖阶段 2 的收支类别-现金流映射与现金流辅助核算约束。
- 利润表季报、现金流量表季报、标准现金流量表（含现金流量调整）。
- 部门利润表 / 项目利润表（依赖辅助核算档案数据）。
- 费用明细表、纳税统计表、财务概要信息。
- 报表统一能力：打印 / 导出 / 分享（微信分享可降级为导出图片）。

**阶段 5 · 平台化**（对标：设置组；规模 M）
- 权限：角色 × 模块 × 操作矩阵、成员管理（制单人 / 审核人分离）。
- 操作日志：页面访问 + 写操作留痕。
- 备份恢复：数据包 + 导出 / 归档（先做数据包与导出，归档 PDF 后置）。
- 账套增强：复制账套、回收站、准则预置科目扩充。
- 旧账导入：先实现"科目余额表导账"单途径，向导式多途径后置。
- 首页财务指标看板（接真实账簿数据）。

**远期 / 按需立项**：发票模块（6 页）、工资模块（4 页）、固定资产模块（5 页）、数据透视表、会计电子档案、老板看账、一键报税。

### 5.3 依赖关系与并行建议

```
阶段1（期末结转）──复用──▶ 账簿聚合（已具备）
阶段2（出纳闭环）──依赖──▶ 辅助核算档案、账户-科目绑定
阶段4（现金流量表）──依赖──▶ 阶段2 的收支类别-现金流映射
阶段4（部门/项目利润表）──依赖──▶ 辅助核算档案数据
阶段2 与 阶段3 相互独立，可并行；阶段5 可穿插进行
```

### 5.4 不建议自研的项（外部依赖，建议降级）

- **银企直连**（需银行开放平台合作）→ 银行对账单导入 + 余额调节。
- **税局直连 / 一键报税**（需税务侧资质）→ 申报表数据导出，供人工申报。
- **发票云采集 / OCR** → 手工发票台账 + 模板导入。
- **收票宝 / 老板看账小程序** → 跨产品联动，不作财务核心立项。

### 5.5 每阶段验收关注点

1. **数字链一致**：凭证（仅已过账）→ 账簿 → 报表，任一层改动必须回归验证。
2. **状态机防跳变**：结账 / 反结账、凭证审核 / 过账不得出现非法状态（如未结转先结账、未过账入账）。
3. **对账恒等式**：试算平衡（借 = 贷）、出纳-总账核对必须有可复现的验证用例。
4. **并行协调**：多会话并发改同一仓时先收敛、再施工，落地前检查工作区在途改动。
