## 附录原文说明段

> 一、会计科目
>
> 会计科目和主要账务处理依据小企业会计准则中确认和计量的规定制定，涵盖了各类小企业的交易和事项。小企业在不违反会计准则中确认、计量和报告规定的前提下，可以根据本企业的实际情况自行增设、分拆、合并会计科目。小企业不存在的交易或者事项，可不设置相关会计科目。对于明细科目，小企业可以比照本附录中的规定自行设置。会计科目编号供小企业填制会计凭证、登记会计账簿、查阅会计账目、采用会计软件系统参考，小企业可结合本企业的实际情况自行确定其他会计科目的编号。

## 抄录备注

- **官方原表只有三列**：顺序号 / 编号 / 会计科目名称，不带余额方向和科目类别标签（类别由「一、资产类」等分组标题体现）。做系统预置时所需的余额方向要按分组标题推导（资产、成本、费用为借；负债、权益、收入为贷；累计折旧/累计摊销/商品进销差价等备抵科目为贷），不能从这张表直接抄出。
- **5403 官方原名是「营业税金及附加」**，《增值税会计处理规定》（财会〔2016〕22 号）把「营业税金及附加」科目改为「税金及附加」，实务与财务软件均已用新名。附录 PDF 2011 年后未修订，仍印旧名。
- 附录同一份 PDF 的第二部分「二、主要账务处理」逐科目给出核算内容、明细核算维度和分录示例，是二级科目与辅助核算口径的官方依据；本文件未抄录。

### 关于「行业有没有更全的带方向科目表」

- **现行不存在行业专属的官方科目表**。1993 年那套分行业会计制度曾按行业各发一本（工业、商品流通、施工、房地产、旅游饮食服务、运输等），配套的补充规定如财会字〔1993〕29 号《工业企业会计制度若干问题的补充规定》、财会字〔1993〕35 号《商品流通企业有关会计处理补充规定》，已在财政部 2015 年发布的废止目录中整体失效。2006/2011 年以后准则统一按企业规模分层（企业会计准则 / 小企业会计准则），不再按行业分表。
- **行业差异靠附注和明细消化，不靠另一张表**：附录第二部分在若干科目正文里直接点名行业，如 1421/1621 标「（农、林、牧、渔业）」、4401 工程施工标「（建造承包商）」、2801 已删的递延税款类不做。所以「最全 + 带方向」的官方来源就是这份附录的两部分合起来读，上表是第二部分的整理结果。
- **比它更「全」的只有企业会计准则那套**：财会〔2006〕18 号附录 A 有 156 个一级科目（同样不带方向，方向在附录 B 的应用指南逐科目说明），行业覆盖写进各科目的应用指南正文。要做预置，两套的取数口径不同，不能混在一张表里。
