# 柠檬云财税 J6 功能清单 &云财差距对照

取证方式：登录 j6.ningmengyun.com（账套「浙江数从科技有限公司」，2026年1月）逐页读取真实 DOM，共 11 个一级模块、约 69 个二级功能点。云财侧结论来自代码盘点（`src/YunCai/Controllers`、`ui/src/pages`、`Domain`）。

## 一句话判定

云财目前只覆盖柠檬云的「记账」这一层：凭证 + 科目 + 日记账 + 4 张报表 + 结账锁期。柠檬云是一整套「记账 + 出纳 + 税务 + 人力 + 资产 + 报表 + 权限」的财务云，**缺口约 50 个功能点**，其中真正的硬缺口只有 3 个体系：**辅助核算、账簿体系（明细账/总账）、期末自动结转**。

## 二、逐页功能细节（第二轮取证，45 页）

### 账簿 `/AccountBooks/*`

所有账页共用一个**隐藏 modal 的「查询条件」面板**（不在可见 DOM 里，必须抓弹层）：期间起止、起止科目（**支持区间表达式**，占位文案「例：5001,5051,5601-5603」）、科目级别、币别（只有综合本位币 / 所有币别 / 人民币三值）、摘要、排序（凭证号 | 凭证日期）、显示辅助核算、只显示最明细、显示对方科目、余额 0 不显示、无发生额且余额 0 不显示、无发生额不显示本期合计/本年累计、显示数量金额。操作统一为：打印当前数据 / 打印所有科目 + 打印设置、导出 / 导出全部、分页 20~1000。

| --- | --- |
| 明细账 | 日期·凭证字号·摘要·借·贷·方向·余额；三栏式 + 数量金额式，可加对方科目列 |
| 总账 | 科目编码·名称·期间·摘要·借·贷·方向·余额；条件无摘要/排序 |
| 序时账 | 日期·凭证号·摘要·科目编码·科目名称·借·贷·**制单人·审核人·附件数·备注**（唯一带审计链的账页） |
| 凭证汇总表 | 科目编码·名称·金额合计·借·贷；表头显示【凭证数 N 张 / 附件数 N 张】 |
| 核算项目明细账 | 辅助类别 + 辅助项目 + 科目 + 级别 + 币别 + 排序；多一个「打印所有核算明细」 |

### 报表 `/Statements/*`

- **现金流量表**：项目·行次·本期·本年累计（可显示上年累计）；33 行项目为小企业准则口径；**「公式法」模式 + 报表底稿**，可微信分享。
- **标准现金流量表**：同一套项目，改为月报/季报 + **「现金流量调整」人工调整**，无公式法。→ 两种制表机制并存。
- **所有者权益变动表**：二级表头（本年/上年 × 实收资本·其他权益工具·优先股·永续债·资本公积·减库存股·其他综合收益·专项储备·盈余公积·未分配利润·合计），按会计年度，**支持「编辑公式」**。
- **部门利润表**：利润表行 × 部门横列（总经办/人力/行政/财务/采购/销售/合计）+ 本期/本年累计；条件月报|季报、核算项目、显示上年同期、无发生额不显示。
- **费用明细表**：科目编码·名称·按月列；默认 5601/5602/5603，展开所有级次、可显示辅助核算。
- **纳税统计表**：应交/已交（增值税、所得税、消费税、城建税、其他、合计）。
- **财务概要信息**：盈利、三项费用、应收应付、资金、税负率；栏为本期·本年累计·金额·同比变化。

## 四、建议「不复刻」的项

这几项不是能力问题，而是依赖外部资质或第三方通道，自研性价比极低：

- **一键报税 / 一键登录税局**：需税局接口与代理资质，建议只做「申报表数据导出」给客户手填。
- **银企互联**：需银行开放平台合作，建议降级为银行对账单（CSV/Excel）导入 + 余额调节表。
- **发票 OCR 采集**：依赖第三方识别服务，可先做手工发票台账 + 模板导入。
- **收票宝 / 老板看账小程序 / 关联进销存**：属于跨产品线联动，不列入财务核心。

## 五、落地顺序建议

P0 里 **辅助核算 → 账簿（明细账/总账/序时账/凭证汇总表）→ 结转损益向导 → 外币+数量核算** 是一条依赖链：账簿和结转模板都要读辅助核算与多币种维度，先做账簿再补辅助核算会返工。P1 资金模块与 P3 固资/工资彼此独立，可并行开分支。

两条前置约束别漏：

1. **账户必须关联会计科目**是资金模块的准入门槛（柠檬云在没关联时直接让核对总账整页不可用），复刻时把「账户 → 科目」做成启用前必填校验。
2. **收支类别要同时承载「智能匹配关键字」和「关联现金流」两张映射**：前者驱动银行流水自动归类，后者驱动现金流量表取数。只做一张表，现金流量表就退化成纯手工调整。

> 取证口径：两轮均用免费版账号（浙江数从科技有限公司，已过期 68 天）逐页读真实 DOM，覆盖 11 个一级模块、45+ 个二级页面。免费版无页面级硬拦截，因此功能地图完整；仍未取到的仅有：发票风险分析的「立即分析」结果明细、旧账导入向导第 ③ 步文案、数据透视表的字段拖拽交互细节（专业版功能）。
